## Methodology

Three lenses applied to the cycle 114 5-point flip rationale:
- **(L1)** Is the four-finding flip threshold itself protective fiction — does it have a named failure mode post-flip?
- **(L2)** Does the flip rationale under-weight Criteria 1+3 (which still favored A) the way cycle 111 under-weighted F4/F11 validation evidence?
- **(L3)** Is "honoring the threshold" being used as a shield against re-examining whether C is actually structurally better, or is it load-bearing structural action?

Each lens applied to the relevant flip rationale points. Findings adversarially reviewed for self-congratulation (per `ITERATION-UNTIL-APPROVAL` applied recursively).

## The three findings

### Finding 1 (Lens 1): the four-finding flip threshold is asymmetric

Cycle 113 named the threshold as: *"if a fourth round of stress-testing surfaces a fourth load-bearing under-weighted dimension favoring C over A, the recommendation should be honestly flipped to C."* The threshold specifies a criterion for A→C but does NOT specify the symmetric criterion for C→A or for the post-flip state where the recommendation stays at C despite findings.

Without a named symmetric counterpart, the threshold operates as a one-way ratchet: it triggered the flip A→C cycle 114 but provides no specification for when the flip should be reversed, when C should be re-examined under similar discipline, or what would count as evidence that C is wrong post-flip.

The pre-flip load-bearing function was interrupting motivated reasoning toward A; the equivalent post-flip function would be interrupting motivated reasoning toward C. The post-flip equivalent is not specified.

**This is a real protective-fiction risk for the post-flip state.** A reader who sees the threshold honored cycle 114 might infer the discipline is settled; in fact the discipline as written applies asymmetrically.

### Finding 2 (Lens 2): Criteria 4+5 cumulative > Criteria 1+3 migration-cost weight is asserted, not derived

The cycle 114 flip rationale point 4 acknowledges Criteria 1+3 still favor A on migration cost (~3600-6200 LOC vs ~5200-8200 LOC PR #2877 revised) but states: *"the flip rests on the orchestrator's tentative analysis that Criterion 5 (central-bet defensibility) cumulative shift to C > A, combined with Criterion 4 (failure-mode addressing depth) cumulative shift to C > B > A under the family-level reading, outweighs Criteria 1 + 3 on the migration-cost dimension."*

**This weighting is asserted, not derived from the redesign prompt's primary thesis.** The redesign prompt SECTION 1 names the primary thesis as: *"the schema-org-json-ld work is the proof domain: useful output that demonstrates the system is actually doing real work, not just theorizing about itself."* Criterion 1 (schema-work-enabling) IS the primary thesis. The prompt does not specify Criteria 4+5 cumulative findings as outranking the primary thesis Criterion 1.

The weighting is a value choice. Like cycle 111's framing weighted F1+F7 dominance over the family-level reading (a value choice cycle 112 found mis-grounded against retrospective text), the cycle 114 weighting privileges Criteria 4+5 cumulative findings over the primary thesis Criterion 1. The two are structurally analogous: cycle 111 picked a reading of dominance that supported A; cycle 114 picked a weighting that supports C. Both pick an interpretation without naming the alternative as a competing reading explicitly Eva-resolves.

Q1+Q2 partially surface this (the "override to A on Criteria 1+3 weighting" framing in Q2). But Q1+Q2 ask about the recommendation outcome, not about the weighting. A reader could approve Q1 thinking they're approving the cumulative findings, without seeing they're also approving the meta-choice that Criteria 4+5 outrank Criteria 1+3 on the primary thesis.

The cycle 114 flip rationale point 3 cites cycle 92 (Aggregate central-bet validation: "carry their weight on F4 and F11"), cycle 96 (PR #2878 absorption: F4 + F11 not qualified as ambiguous-without-prototype), and cycle 107 (Risk 2 closure at specification level with falsifiable thresholds) as direction-validating evidence accumulated for C across 4 cycles.

Cycle 96 PR #2878 was a Copilot absorption working from the orchestrator's framing (the Copilot lens was on sharpening claims, not on adversarial critique of C's overall thesis). Cycle 107 is the orchestrator's own risk closure at specification level — internal authoring.

## Lexicon entries

- **meta-reflexive stress-test**: applying the same adversarial framing the orchestrator applied to a prior recommendation to the current recommendation's rationale. Cycle 115 first instance: cycle 114 flip rationale tested with cycle 112-114 methodology.
- **motivated-reasoning surface**: an aspect of a framing where the reasoning is asserted or selectively cited rather than derived from substrate. Distinguishable from "actually wrong" — motivated reasoning can produce correct outcomes by accident, but the rigor is missing.
- **asymmetric threshold**: a falsifiable criterion that specifies one direction of state transition but not the other. The cycle 113 four-finding threshold (A→C) without a named C→A counterpart.
- **symmetric flip-back threshold**: the cycle 115 introduction. Specifies 4 substrate-content-distinct findings favoring A over C OR substantively undermining the flip rationale, in cycle 116+ object-level C-side stress-testing, would trigger flip-back to A.
- **per-selection-draft framing**: claims and reasoning specifically in the selection draft (2-selection.md), distinct from per-candidate document content (A-evolved-single-orchestrator.md, C-hybrid.md). Cycles 111-114 stress-tested A's per-selection-draft framings.
- **one-way ratchet**: a falsifiable criterion that operates in one direction only, with no specification for the reverse direction. Cycle 113's threshold was a one-way ratchet until cycle 115 named the symmetric counterpart.
- **recursive motivated-reasoning surface**: the meta-pattern where each cycle's framing has motivated-reasoning surfaces revealed by the next cycle's stress-test. Potentially unbounded if the pattern HARDENS across multiple cycles.
- **value choice vs analysis**: distinguishing claims that derive from substrate (analysis) from claims that pick an interpretation among alternatives (value). Q7 cycle 115 surfaces the weighting choice as value, not analysis.
- **provisional flip**: a flip whose rationale has acknowledged motivated-reasoning surfaces and which is therefore pending further work. Cycle 115 framed the cycle 114 flip as provisional pending cycle 116+ symmetric C-side stress-testing.

## Meta-observation: cycle 115 as the honest cycle of cycles 111-115

Cycles 111-114 progressively dismantled A's case while keeping the recommendation at A until cycle 114's flip. **Cycle 115 is the first cycle in the 111-115 arc that examines the orchestrator's own framing rather than the prior recommendation's framing.** This is structurally important:

- Cycle 111 framed A's case (motivated reasoning in cycle 111).
- Cycle 112 found cycle 111's framings (orchestrator's stress-test of orchestrator's own prior work).
- Cycle 113 found cycle 112's reframings (orchestrator's stress-test of orchestrator's own reframings).
- Cycle 114 found cycle 111's "Why not C" Reason #1 AND honored the threshold (orchestrator's stress-test of cycle 111 + structural action).
- Cycle 115 found cycle 114's flip rationale (orchestrator's stress-test of orchestrator's own structural action).

The discipline is recursive: each cycle examines the prior cycle's framing AND its own framing becomes the next cycle's target. The discipline survives because each cycle's findings are substrate-content-distinct from prior cycles' findings.

**The cycle 115 honest meta-observation:** if this pattern continues without bound (cycle 116 finds motivated reasoning in cycle 115; cycle 117 finds in cycle 116; etc.), the discipline becomes self-sustaining iteration without conclusion. The candidate-selection checkpoint is gated on Eva's approval; if the orchestrator's meta-reflexive iteration converges, Eva can approve when she reads a stable artifact. If the meta-reflexive iteration does not converge, the cycle 115 symmetric threshold provides the falsifiable criterion for resolution: 4 substrate-content-distinct findings against C in cycle 116+ flips back to A; fewer than 4 stabilizes at C.

**The cycle 115 framing predicts a stabilization within 3-5 cycles** (cycles 116-120) under either: (a) cycle 116-118 symmetric C-side stress-testing finds 4+ substrate-content-distinct findings → flip-back to A; (b) cycle 116-118 finds <4 substrate-content-distinct findings → C confirmed as stable recommendation; (c) audit cycle 216+ critique landing surfaces independent evidence that confirms or refutes the cycle 114 flip; (d) Copilot adversarial dispatch (once #2903 resolves) provides external adversarial framing.

The candidate-selection checkpoint thus has a defined convergence horizon: cycle 116-120 stabilization expected, with Eva's approval as the final gate. The cycle 115 work makes this horizon visible and provides falsifiable criteria for resolution rather than indefinite iteration.
